# План перехода на NetBox-first

Этот файл — рабочий чек-лист миграции.

**NetBox-first** означает: NetBox является главным источником данных о
провайдерах, контурах и подключениях. Скрипт читает эти данные, получает
статистику с оборудования и настраивает мониторинг.

## Главные правила

- [ ] Скрипт не создаёт Provider.
- [ ] Скрипт не создаёт Circuit.
- [ ] Скрипт не создаёт Circuit Termination.
- [ ] Скрипт не создаёт Cable.
- [ ] Скрипт не удаляет Provider, Circuit, Termination или Cable.
- [ ] Скрипт не заменяет существующий кабель другим.
- [ ] Старый код автоматического создания сначала отключается, а затем удаляется
      после успешной миграции.
- [ ] Старые данные NetBox сохраняются.

## Целевая цепочка

```text
Provider
  -> Circuit
  -> Circuit Termination A
  -> Cable
  -> Interface
  -> Device с тегом border
  -> SSH-опрос
  -> обновление разрешённых полей интерфейса
  -> Zabbix
```

В мониторинг попадает только полная цепочка до устройства с тегом `border`.

## Решение по плагинам

На первом этапе плагины не устанавливаем.

Стандартных объектов NetBox и дополнительных полей достаточно для текущей
задачи. `netbox-contract` можно рассмотреть отдельно, если потребуется
полноценный учёт договоров, счетов и стоимости. Это не должно блокировать
переход на ручное создание подключений.
